- 所有视频打包为**一个 `.zip`**，命名格式 **「实训战队名称＋队伍名称＋队长姓名」**；
- 本队对应文件名：**`GSing随缘张川.zip`**（作为邮件附件提交，不放入仓库，避免视频重复占用空间）；
